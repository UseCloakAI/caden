# Caden

Multi-device home voice agent. Static web app (no build) + Android WebView wrapper. See README.md for the architecture.

- Web app files ship as-is: `index.html`, `css/`, `js/`, `icons/`, `manifest.webmanifest`, `sw.js`. The Android app bundles the same files (`android/app/build.gradle` `syncWeb`) — new top-level web files must be added there, to `SHELL` in `sw.js`, and to the Pages stage step in `.github/workflows/ship.yml`.
- Bump `CACHE` in `sw.js` when shipping changes to shell files.
- Design: one accent (coral; `--acc-ink` for coral text, `--on-acc` for text on coral fills), text colors checked against WCAG AA. Shapes: controls are pills, inputs 16px, cards/sheets 24px. Icons are Phosphor (`icons/ph`, vendored); no emoji, no hand-drawn SVG icons. Fonts are self-hosted (`fonts/`). No em-dashes or middot chains in UI copy.
- Brain = Caden Supabase project (`wiimiqqmdmfikuqgqhtm`) edge function `brain`; model = Cloak `/v1/chat` `model:"kairos"` (NVIDIA Nemotron first). Caden uses Cloak's general endpoints (`/v1/chat` kairos, `/v1/speech`) but no Caden-specific code lives in the Cloak repo; keep it that way. Background/utility work must not use chat tiers.
- Touch-free display mode (`html.display`, `settings.display`, `#display`): hand tracking. `js/hands.js` turns MediaPipe Gesture Recognizer output into a pointer (index knuckle, so pinching doesn't move it), pinch state and gestures (wave / swipe / thumbs up / thumbs down / fist rests); its `analyze(hands, t)` is pure and unit-testable. `js/airnav.js` owns the cursor, pinch-to-press (on release, so a drag cancels it), pinch-drag scroll and the hand preview. Air targets exclude external links and downloads (a kiosk must not navigate away). Faces and hands share `js/camera.js`; never open a second `getUserMedia`. `?debug` exposes `window.__caden` for tests.
- Voice: Cloak API `POST /v1/speech` (NVIDIA Magpie TTS Multilingual on Cloak's key pool; `GET /v1/speech/voices`). `Mouth` prefetches per sentence and must always fall back to the device voice on any error.
- Voice location (`js/locate.js`): wake-word loudness minus this device's calibration, shared as `heard` mesh messages; loudest wins after `ARB_MS`. Never use AGC on the meter stream. A device that's alone must act immediately.
- APK updates (`android/.../Updater.java`): web builds come from Pages `version.json` (per-file SHA-256, verified, swapped atomically into `files/www`, applied when JS says Caden is idle); native updates only when the `native` source hash changes and both builds are stable-signed (CI secrets). `app.json` in the APK and `version.json` on Pages share `github.run_number` as the build number. Never serve a web file that failed its hash.
- Sounds (`js/sfx.js`): synthesized only (no audio files), rendered once per sound at 48 kHz stereo, peak-normalized to 0.7, faded edges, then a limiter on playback. UI sounds stay dry (`SPACE`). Keep new sounds in the D-major pentatonic palette and quiet next to speech.
- Join QR (`js/qr.js`): encodes `PUBLIC_URL#join=<code>` (never `location.origin`: the APK serves from caden.app). It's the home key: hidden until asked, auto-hides after 2 min.
- Mesh payloads are always encrypted (`js/mesh.js`); never send plaintext over Realtime, and never send camera frames anywhere.
- LAN links (`js/lan.js`): one WebRTC data channel per device, signaled through the mesh as `rtc` messages (consumed inside the mesh, never dispatched). Routing in `Mesh.send`: links first; relay when a known device has no open link, the packet is over `MAX_DC`, or the type is in `RELAY_ALWAYS` (`hello`/`beat`/`bye`/`rtc`, so new devices are found). Messages are deduped by id, so double delivery is fine. `lan.known` tracks every device heard from; a dropped link must never make messages to that device disappear.
- The holder protocol (claim / handoff / epoch) is in `js/app.js` — keep "highest epoch wins, ties to lower id".
- Replies are spoken: the playbook is `HOME_NOTE`, in two copies that must stay identical: `supabase/functions/brain/index.ts` and `js/config.js` (direct-to-Cloak fallback).
- Motion identity (Playful): tokens `--e-out/--e-pop/--e-in/--e-sine` + `--t-quick/std/slow` in `css/caden.css`, mirrored as `E`/`T` in `js/orb.js`. Entrances decelerate and rise 12px, exits accelerate and run ~35% shorter. Flights arc with keyframes every <1/3 screen, with three layers: orb, ground shadow + trailing face, sparks + room light (`html.is-away` dims it). Staggers stay under 400ms. Animate `translate`/`scale`/`opacity` (the dock puck also animates `width`).
- Respect `prefers-reduced-motion` (orb flights degrade to fades, CSS durations collapse).
